# Improved version of Finding the Hypotenuse of a Right Triangle using Math Library
# -----------------------------------------------------------------
## Description:
### This program will allow you to find the hypotenuse of a right triangle (as mentioned in the title.)
## Running the program:
### Download the file and use a Python engine such as PyCharm, or an online website that allows you to run Python files.
## Input Needed:
### If you're confused about what to type, no worries! Just input the length of the bottom of the triangle, and the side! Do not worry about the length of the diagonal, which is what we're solving for. Here's an example of how you should do it:
## Sample Code
# -----------------------------------------------------------------
### import math
### a = float(input("enter length of side a: "))
#### (Here's where to put the length of the first side, whether it be the side or bottom)
### b = float(input("enter length of side b: "))
#### (Here's where to put the length of the other side)
### asq = math.pow (a,2)
### bsq = math.pow (b,2)
### hypotenuse = math.sqrt(asq + bsq)
### print(f"The hypotenuse is {hypotenuse:.2f}")
# -----------------------------------------------------------------
